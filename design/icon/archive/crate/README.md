# Crate icon (superseded)

The previous launcher icon: a cream crate with a play window on a deep-rose
gradient. It was replaced by the TV mark in `design/icon/build_icons.py`, and
is kept here only as a reference for the earlier direction.

`build_icons.py` in this folder is the old generator. Its paths are relative to
this directory, so it no longer writes into the app; run the parent script for
the icon the app ships with.
